🦷 Assistant IA pour cabinet dentaire

Le dentiste dicte, l'IA construit le plan de traitement (étapes, intervalles, prix), pose ses questions et régénère le PDF.

🧠 Moteur

L'IA open source se télécharge une seule fois (elle démarre dès que vous commencez à dicter) puis reste en cache. Le plan est calculé sur votre ordinateur, sans serveur ni clé API.
Votre navigateur ne supporte pas WebGPU : l'IA ne peut pas tourner ici, le mode rapide est utilisé. Pour l'IA : Chrome ou Edge récent sur ordinateur.
